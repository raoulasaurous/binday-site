# Councils Wheelie covers

Wheelie has live collection dates for **133 UK councils** — around
40% of the country by population — and more are added regularly.

Dates come from each council's own published data, so bank-holiday changes
are already included.

**Your council missing?** Email [support@wheelie.day](mailto:support@wheelie.day?subject=Council%20request)
and say which one. Some councils publish nothing an app can read — if yours
is one of those, the app will tell you so rather than guessing.
